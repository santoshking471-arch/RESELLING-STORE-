# Santosh Store 🛒

Ye ek simple reselling website hai jo Firebase par based hai.

## 🔥 Features
- User Signup / Login system
- Product listing with image
- Price show hota hai
- Buy button se order place hota hai
- Customer details (Name, Phone, Address) li jati hai
- Orders Firebase me save hote hai
- Admin orders dekh sakta hai

## 👤 Admin
- Admin email se login karke products manage kar sakta hai
- Orders check kar sakta hai

## 🛍️ Customer Features
- Product dekh sakta hai
- Image click karke details dekh sakta hai
- Buy Now se order kar sakta hai
- Price clearly show hoti hai

## ⚙️ Technologies Used
- HTML
- CSS
- JavaScript
- Firebase (Auth + Firestore)
